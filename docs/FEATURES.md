# 功能与验证清单

“通过”只代表右栏给出的测试范围；实现不等于已在全部设备/网站验证。

| 功能 | 状态 | 证据 / 限制 |
|---|---|---|
| Kotlin、Compose、Material3、MVVM、8职责模块 | 已实现/构建通过 | Gradle工程和Lint |
| 多URL、粘贴、分享入口、最近记录 | 已实现 | URL单测；Activity分享实际跨应用仍待人工验收 |
| 异步解析、取消、超时、分类失败 | 已实现 | HTTP/进程取消；部分技术错误英文 |
| 直接图片/视频/音频Content-Type识别 | 已实现 | HTTP fixture、PNG/WAV设备下载 |
| 网页图片 src/srcset/picture/lazy/OG/背景 | 已实现，单测通过 | 静态HTML；无JS渲染和候选坏图自动回退 |
| 图片网格、多选/全选、已知宽度/格式筛选 | 已实现 | 真实PNG批量测试；未知尺寸不会伪造 |
| SHA256图片去重、并发发布串行 | 已实现，设备通过 | 同内容共享有效输出；不同内容同名不覆盖 |
| yt-dlp真实格式、分辨率、时长/封面、播放列表 | 已实现，部分实测 | 本地DASH真实120p格式；播放列表及封面逐站未验收 |
| 实际格式下载、MP4优先，合并后确认轨道 | 已实现，设备通过 | 本地DASH → yt-dlp视频/音频 → FFmpeg → 双轨校验 |
| 音频选择、MP3/M4A/Opus、直接视频MP4转换 | 已实现，设备通过部分 | FFmpeg实际音频转换；网站编解码器覆盖不保证 |
| HTTP验证式Range、非法Range、416、截断重试 | 单测通过 | 强 ETag、严格 Content-Range、SHA-256 检查点、损坏/未提交尾部恢复 |
| 断开连接后恢复 | 单测通过 | 本地Socket中断后从验证的字节位置恢复 |
| 队列、1–4并发、进度/速度/ETA、任务限速 | 已实现 | HTTP真实字节；网站JSON进度，未知总量不伪造 |
| 暂停/继续/取消/重试、迟到回调保护 | 已实现，设备通过部分 | 任务取消与服务通知action测试；转换阶段取消待长时压力 |
| Room重启恢复、SAVING输出校验与补提交 | 已实现；新增测试待设备执行 | v1→v2 保留任务迁移、活动任务暂停、失败历史保留；既有发布日志测试不等于物理断电验证 |
| yt-dlp/HLS/DASH中断恢复 | 已实现，策略与文件检查点单测通过 | 同次 continue/part；跨进程保留旧分片并隔离重下，完整媒体校验后复用；原生设备回归待跑 |
| 恢复状态、存储不足、清理保护 | 已实现/构建验证 | 中/日/英恢复提示、ENOSPC停止自动重试、清理需确认；真实磁盘满待设备验证 |
| Android前台服务、通知暂停/取消 | 已实现，Android15通过 | 模拟器实际服务动作测试 |
| Home后台、锁屏继续 | Android15模拟器通过 | 本地WAV短时测试，不代表长时Doze/OEM |
| Android14/15/16限制处理 | 已实现/部分验证 | FGS类型/权限、超时stop、无后台无限重启；14/16未跑 |
| MediaStore Downloads/相册、SAF选择目标 | 已实现，MediaStore通过 | SAF提供者、撤销权限/空间不足待机型验收 |
| 重名自动编号、完成后打开/分享 | 已实现 | 重名和校验设备通过；外部查看器人工待验收 |
| 中/日/英、浅深系统主题、默认画质、命名 | 已实现，资源构建通过 | 核心控件已翻译；动态技术错误英文，尚未全面视觉验收 |
| Wi-Fi限制、目录、并发、速率设置持久化 | 已实现 | 活动网络定期检查，限速变更用于新建/重启任务 |
| 手动Cookies导入/删除、Keystore加密、授权主机 | 设备通过 | 受控测试Cookie，未使用真实私人Cookie |
| 本地历史清理、临时数据清理 | 已实现 | 不删除已完成用户文件 |
| APK与CI、架构/移植/签名/许可文档 | 已交付 | APK本机构建；CI远端未运行 |
| arm64物理设备 | 未验证 | 已打包arm64库及专用APK |
| 16KB媒体运行时 | 已知缺口，有降级 | 原生WebP依赖未对齐；大页面禁用yt-dlp/FFmpeg |
| 正式分发的完整原生对应源码 | 待审核 | 不能用Maven坐标代替GPL对应源码 |
